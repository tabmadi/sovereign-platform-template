# Values keys that a deployed environment can carry and the local overlay does not.
# Each key has a divergence that ADR-0205 permits. lint:parity fails a deployed key
# that is absent from the local overlay and not listed here. The local tier covers
# the code path before a deployed environment adds configuration for it. Every
# entry has a reason, and a reviewer judges the reason.

externalObjectStorage            # prod's off-cluster bucket, which is absent below prod
policies.registrySecret           # the local registry is unauthenticated
lowdefy.image.digest             # promoted images are pinned by digest, and local runs from a tag
lowdefy.imagePullSecrets         # registry auth, only on deployed environments
publicTls                        # ACME and the deployed apex. Local uses a self-signed wildcard
maddy                            # the mail agent, only on deployed environments
maddyEnabled                     # the mail agent's toggle, only on deployed environments
alertmanager.email               # alert routing, only on deployed environments, per ADR-0502
grafana.replicas                 # scale
loki.singleBinary.replicas       # scale
tempo.replicas                   # scale
podDisruptionBudgets             # HA exists only with more than 1 replica
resourceQuotas                   # quotas sized for the full platform
cluster.backup.serverName        # the archive that a restore writes to, per environment. See docs/guide/disaster-recovery.md
cluster.recovery                 # the bootstrap of a restore, set only while a restore runs
